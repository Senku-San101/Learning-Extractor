# Learning Extractor

A Chrome extension that tracks AI chats you are learning from, with progress checkboxes (Explained, Quizzed, Gaps), a side panel that shows the chosen chat, and learning nudges.

## Install (developer mode)
1. Download the latest release and unzip it.
2. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and pick the unzipped folder.

## Updates
The extension checks this repository's latest GitHub release once a day. When a newer version is available it shows a badge and a link in **Options → Updates**.
